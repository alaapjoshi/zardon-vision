Zardon Vision

My Story

One afternoon at the library, I noticed a young boy struggling to read a novel. After talking with him, I learned that he was visually impaired and had forgotten his glasses at home. That stuck with me, and I decided to build an app that could help him and others like him. Zardon Vision uses the phone's camera to read text and describe surroundings out loud. I designed it with large, high-contrast buttons, and every screen announces itself when it opens, so it can be used without reading the screen.

Object Recognition

The user takes a photo, and the app uploads it to a Flask server running a ViT-GPT2 image captioning model built with PyTorch and Hugging Face Transformers. The server sends back a one-sentence description, such as "a large body of water with mountains", and the app reads it out loud.

Text Recognition

The user scans a page with the document camera, which finds the edges of the page automatically. Apple's Vision framework then recognizes the text on the device, with language correction turned on, and the app reads each page out loud. It works on books, documents, and signs, and it does not need an internet connection.

Depth Perception

Depth is perceived through disparity: each eye sees a slightly different view, and the brain uses the difference to judge distance. The iPhone's TrueDepth camera works on a similar idea. The Depth Perception tab is my starting point for using that data to help people sense how far away objects are.

Help Center

The Human Help Center lists helpers and shows who is available. One tap starts a FaceTime call, and each helper has a profile with their time zone and a short bio. The home screen also has a panic button and shortcuts to open apps like Uber and Uber Eats.

Technologies

I built the app in SwiftUI, with UIKit for the camera. Text recognition uses Apple's Vision and VisionKit, and all spoken feedback uses AVFoundation. Image captioning runs on a Python server with Flask, PyTorch, and Hugging Face Transformers. This website is plain HTML and CSS.

Struggles

This was my first time doing Swift and app development. SwiftUI was still new and had gaps, especially around the camera, so I used UIKit for those parts. Design was also hard: the app had to work for people who cannot rely on seeing the screen, so I went through many layouts before settling on big buttons and spoken feedback. I also tried training a facial recognition model with Create ML, but it overfit to its training data and was not accurate enough to ship. That is on my list for next time.

Impact

Zardon Vision makes written information and everyday surroundings easier to access for people with low vision. It won 2nd place overall at MontyHacks VI.
